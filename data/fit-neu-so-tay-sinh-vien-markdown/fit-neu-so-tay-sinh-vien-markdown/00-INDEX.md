# Danh mục Sổ tay sinh viên FIT-NEU

## Phạm vi

- Nguồn chính: https://fit.neu.edu.vn/post/so-tay-sinh-vien

## Quy ước cấu trúc

- `#`: tên tài liệu.
- `##`: metadata và khối nội dung.
- `###`: nhóm chủ đề hoặc chương.
- `####`: mục con.
- `-`: ý chính.
  + `+`: ý cấp con khi cần.

## Tệp máy đọc

- `manifest.json`: metadata, URL nguồn, kích thước và SHA-256 từng file.
